# Sahar Shiri Portfolio (Final)

این پروژه یک وب‌سایت استاتیک و واکنش‌گرا برای معرفی خدمات و نمونه‌کارهای **Sahar Shiri** است.

## اجرا
فقط فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. تمام فایل‌های این پوشه را در ریشه repository آپلود کنید.
3. در GitHub به مسیر **Settings > Pages** بروید.
4. گزینه **Deploy from a branch** را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/ (root)` قرار دهید.
6. ذخیره کنید تا لینک آنلاین سایت ساخته شود.

## اطلاعات قابل ویرایش
در فایل `index.html` این مقادیر را با اطلاعات واقعی جایگزین کنید:
- `hello@example.com`
- `your_username` برای اینستاگرام و تلگرام
- `+98 000 000 0000`
- `تهران، ایران`

## ساختار فایل‌ها
- `index.html` — صفحه اصلی
- `styles.css` — استایل‌ها
- `script.js` — اسکریپت‌های منو، لایت‌باکس و انیمیشن ساده
- `assets/images/` — تصاویر پروژه و پرتره
- `assets/logo.svg` — لوگوی انگلیسی SAHAR SHIRI

## نکته
این نسخه بر اساس استایل مرجع کاربر بازطراحی شده و برای دسکتاپ و موبایل بهینه است.
